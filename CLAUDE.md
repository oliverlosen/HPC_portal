# Entrada para Claude

La guía compartida de este repositorio es `AGENTS.md`, importada arriba. Mantén las reglas generales allí para que Claude, Codex y los demás agentes trabajen con el mismo criterio.

Al iniciar una tarea, lee el contexto de `PROYECTO.md`, el `README.md` y las entradas más recientes de `ULTIMOS_CAMBIOS.md`. Cuando modifiques archivos, actualiza el registro de cambios siguiendo la plantilla compartida.

Si usas Claude en un chat que no carga archivos de proyecto automáticamente, pide o abre explícitamente estos documentos desde la rama en la que vas a trabajar.
